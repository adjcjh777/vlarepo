# 模式识别作业 PPT

本目录包含一份可直接用于课堂分享的 100 页 PPT 成品，以及对应的可编辑生成脚本。

## 主要文件

- `output/模式识别_五家公司案例研究_100页.pptx`
  最终 PPT 成品。
- `build_pattern_recognition_100.js`
  使用 PptxGenJS 生成 PPT 的源码。
- `pptxgenjs_helpers/`
  生成脚本依赖的辅助库。

## 重新生成

在 `/Users/junhaocheng/working-dir` 下执行：

```bash
node pattern_recognition_ppt/build_pattern_recognition_100.js
```
