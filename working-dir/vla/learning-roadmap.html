📐 1.3 三维几何基础

这是理解运动表示的基石。旋转的表示方式直接影响扩散模型的设计。

核心概念：

  • 欧拉角 (Euler Angles)：三个角度表示旋转，直观但有万向锁 (Gimbal Lock) 问题
  • 旋转矩阵 (Rotation Matrix)：3x3 正交矩阵，SO(3) 群，det(R)=1，R^T R = I
  • 四元数 (Quaternion)：4 个参数表示旋转，无万向锁，q = [w, x, y, z]，单位四元数 |q|=1
  • 轴角 (Axis-Angle)：一个旋转轴 + 一个旋转角度，通过 Rodrigues 公式转旋转矩阵
  • 6D 旋转表示：用旋转矩阵的前两列（6 个数）表示旋转，再通过 Gram-Schmidt 正交化恢复 — 这是运动扩散模型中最常用的表示
  • 齐次变换矩阵：4x4 矩阵统一表示旋转和平移，T = [R t; 0 1]

推荐资源：

  • 论文 "On the Continuity of Rotation Representations in Neural Networks" (Zhou et al., CVPR 2019) — 提出 6D 旋转表示，运动扩散模型必读
  • 视频 3Blue1Brown — "Visualizing quaternions" — 四元数的最佳直觉解释

🦴 2.1 人体模型：SMPL / SMPL-X / SOMA

SMPL 是目前最广泛使用的参数化人体模型，几乎所有运动扩散模型都基于它。

核心概念：

  • SMPL 模型：输入形状参数 β（10 维）和姿态参数 θ（72 维 = 24 关节 x 3），输出人体网格（6890 个顶点）
    · Shape Space：由 PCA 学习的身体形状变化
    · Pose Space：24 个关节点的轴角旋转
    · Linear Blend Skinning (LBS)：将顶点绑定到骨骼并变形
  • SMPL-X：扩展版，加入手部（MANO）和面部（FLAME），总参数更多
  • SOMA：NVIDIA 的骨架模型，用于 Kimodo 的人形机器人运动表示
  • 关键理解：SMPL 的姿态参数 θ 经过不同表示（轴角/6D）后就是扩散模型的生成目标

推荐资源：

  • 论文 "SMPL: A Skinned Multi-Person Linear Model" (Loper et al., SIGGRAPH Asia 2015)
  • 论文 "SMPL-X: A Unified Model" (Pavlakos et al., CVPR 2019)
  • 代码 smplx — SMPL/SMPL-X 的 PyTorch 实现
  • 代码 smpl-pytorch — 纯 PyTorch 实现
  • 视频 YouTube 搜索 "SMPL body model explained"

🦾 2.2 机器人运动学

理解机器人是如何通过关节角度来控制末端位置的，这是 VLA 系统最终需要输出的内容。

核心概念：

  • 正运动学 (FK)：给定所有关节角度，计算末端执行器位置 — 本质是齐次变换矩阵的链乘
  • 逆运动学 (IK)：给定末端位置，求关节角度 — 通常用数值方法（雅可比矩阵迭代）
  • URDF 文件：Unified Robot Description Format，XML 格式描述机器人结构
    · link: 刚体连杆（质量、惯量、碰撞几何）
    · joint: 关节类型（revolute/prismatic/continuous/fixed）
    · 关节限位、阻尼、摩擦
  • 关节空间 vs 笛卡尔空间：在关节空间做扩散 vs 在笛卡尔空间做扩散的区别
  • DH 参数：Denavit-Hartenberg 约定，经典但实际中常用 URDF 替代

推荐资源：

  • 书籍 Modern Robotics (Lynch & Park) — 免费在线，第 2-6 章
  • 课程 Robotics: Aerial Robotics (UPenn, Coursera) — 运动学基础
  • 代码 DeepMind dm_control — MuJoCo 的 Python 封装，可加载 URDF
  • 视频 YouTube 搜索 "forward inverse kinematics tutorial"

🎬 2.3 动捕数据与格式

运动扩散模型的训练数据来源。理解数据从哪里来、长什么样，是理解模型的第一步。

核心概念：

  • BVH 格式：Biovision Hierarchy，文本格式存储骨骼层级和每帧旋转
    · HIERARCHY 部分定义骨骼树
    · MOTION 部分存储每帧的旋转数据
  • AMASS 数据集：大规模统一动捕仓库，将 300+ 个数据集统一到 SMPL 参数空间
    · 论文：AMASS: Archive of Motion Capture as Surface Shapes
    · 网站：amass.is.tue.mpg.de
  • HumanML3D 数据集：基于 AMASS 的文本-运动对数据集（~14,600 对）
    · 论文："HumanML3D: A Large and Diverse Multi-modal Human Motion Dataset"
    · 包含文本描述和对应的 SMPL 运动序列
  • FK 输出格式：从关节角度通过正运动学得到的 3D 关节位置
  • 关键理解：动捕数据 → SMPL 拟合 → 参数化表示 → 扩散模型训练数据

  • 代码 HumanML3D 数据处理代码

🔄 2.4 运动表示方法

不同的运动表示方式对扩散模型的性能影响巨大。这是 Phase 2 最核心的内容。

核心概念：

  • 关节角度 (Joint Angles)：最直观，但有不连续性和万向锁问题
  • 旋转矩阵 (Rotation Matrices)：连续但冗余（9 个数表示 3 DOF），直接在 R^9 上做扩散需要投影回 SO(3)
  • 6D 旋转表示：6 个数表示旋转，连续且相对紧凑，通过 Gram-Schmidt 正交化恢复旋转矩阵 — 这是 MDM 和 Kimodo 的选择
  • 四元数：4 个数，有双覆盖问题（q 和 -q 表示同一旋转），不适合直接做扩散
  • 轴角 (Axis-Angle)：3 个数（方向=旋转轴，模长=角度），有不连续性
  • 位置表示：直接用 3D 关节位置（通常在根节点归一化的坐标系下）

为什么 6D 表示最好？

Zhou et al. (CVPR 2019) 证明了：从 R^n 到 SO(3) 的连续映射，n 至少需要 5。6D 表示是满足连续性的最小实用维度，且可以通过简单的 Gram-Schmidt 过程映射回 SO(3)。

📊 3.1 Score Matching 与去噪分数匹配

扩散模型的理论根基。理解"分数"（score）的概念是理解整个扩散模型框架的关键。

核心概念：

  • 分数函数 (Score Function)：s(x) = ∇_x log p(x)，即数据分布对数概率的梯度
    · 不需要知道归一化常数，只需要知道梯度方向
    · 分数指向数据密度增长最快的方向
  • Score Matching (Hyvarinen, 2005)：直接学习分数函数，但对高维数据计算量大
  • Denoising Score Matching (Vincent, 2011)：通过加噪 → 去噪来隐式学习分数
    · 给数据加高斯噪声：x̃ = x + σε
    · 训练网络预测噪声方向（即分数方向）
  • Noise Conditional Score Network (NCSN)：在不同噪声尺度上学习分数函数

推荐资源：

  • 论文 "Generative Modeling by Estimating Gradients of the Data Distribution" (Song & Ermon, NeurIPS 2019)
  • 视频 Yang Song — ICML 2022 Tutorial on Diffusion Models — 作者亲自讲解

🌊 3.2 DDPM (Denoising Diffusion Probabilistic Models)

现代扩散模型的奠基之作。这是你必须深入理解的核心论文。

核心概念：

  • 前向过程 (Forward Process)：逐步给数据加高斯噪声
    · q(x_t | x_{t-1}) = N(x_t; √(1-β_t) x_{t-1}, β_t I)
    · β_t 是方差调度 (variance schedule)，通常从 1e-4 线性增加到 0.02
    · 可以一步到位：q(x_t | x_0) = N(x_t; √ᾱ_t x_0, (1-ᾱ_t) I)，其中 ᾱ_t = ∏_{s=1}^t (1-β_s)
  • 反向过程 (Reverse Process)：逐步去噪
    · p_θ(x_{t-1} | x_t) = N(x_{t-1}; μ_θ(x_t, t), Σ_θ(x_t, t))
    · 训练网络预测噪声 ε_θ(x_t, t)
  • 训练目标：L = E_{t,x_0,ε} [||ε - ε_θ(x_t, t)||²]
    · 惊人地简洁：就是预测加的噪声
  • 采样过程：从纯噪声开始，迭代去噪
    · x_{t-1} = (1/√(1-β_t)) (x_t - (β_t/√(1-ᾱ_t)) ε_θ(x_t, t)) + √β_t z

推荐资源：

  • 论文 "Denoising Diffusion Probabilistic Models" (Ho et al., NeurIPS 2020) — 必读原文
  • 视频 Yannic Kilcher — "Diffusion Models | Paper Explanation" — 逐公式讲解 DDPM
  • 视频 Caltech CMS 155 — Diffusion Models Lecture
  • 代码 DDPM 官方代码 (TensorFlow)
  • 代码 lucidrains/denoising-diffusion-pytorch — 清晰的 PyTorch 实现，强烈推荐

⚡ 3.3 DDIM 与加速采样

DDPM 需要 1000 步采样，太慢了。DDIM 通过非马尔可夫过程实现大步跳跃。

核心概念：

  • DDIM 的关键洞察：DDPM 的训练目标可以用于一族非马尔可夫前向过程
  • 确定性采样：当 η=0 时，DDIM 采样是确定性的（给定初始噪声 x_T，输出唯一）
  • 加速采样：只用 50 步甚至 10 步就能得到不错的结果
  • 隐空间插值：因为 DDIM 是确定性的，可以在 x_T 空间做有意义的插值

推荐资源：

  • 论文 "Denoising Diffusion Implicit Models" (Song et al., ICLR 2021)
  • 代码 DDIM 官方代码

🎛️ 3.4 Classifier-Free Guidance (CFG)

条件生成的杀手锏。所有文本驱动的运动扩散模型都使用 CFG。

核心概念：

  • Classifier Guidance：用分类器的梯度引导生成，但需要额外训练分类器
  • CFG：不需要额外分类器！同时训练有条件和无条件模型
    · ε̃ = ε_θ(x_t, t, ∅) + w · (ε_θ(x_t, t, c) - ε_θ(x_t, t, ∅))
    · w 是引导强度，∅ 是空条件（通常用空字符串或零向量）
    · w > 1 时生成质量提高但多样性降低
  • CFG 在运动生成中的应用：w 通常设为 2.5-7.5，控制文本描述的遵循程度

推荐资源：

  • 论文 "Classifier-Free Diffusion Guidance" (Ho & Salimans, NeurIPS 2021 Workshop)

🎯 3.5 一致性模型 (Consistency Models) & LCM

进一步加速：1-2 步生成。MotionLCM 就是基于这个思路。

核心概念：

  • 核心思想：训练一个模型，使得 ODE 轨迹上的任意点都能直接映射到起点 x_0
  • 自一致性 (Self-Consistency)：f_θ(x_t, t) = f_θ(x_{t'}, t')，对任意 t, t' 成立
  • LCM (Latent Consistency Models)：在隐空间中训练一致性模型，进一步加速
  • 蒸馏训练：从预训练的扩散模型蒸馏到一致性模型

推荐资源：

  • 论文 "Consistency Models" (Song et al., ICML 2023)
  • 论文 "Latent Consistency Models" (Luo et al., 2023)

🌊 3.6 Flow Matching

比扩散模型更简洁的框架，pi0 和一些最新运动模型使用此方法。

核心概念：

  • 连续归一化流 (CNF)：学习一个速度场 v_θ(x_t, t)，将噪声分布传输到数据分布
  • Flow Matching：直接回归条件向量场
    · 插值路径：x_t = (1-t) x_0 + t x_1，其中 x_0 是噪声，x_1 是数据
    · 目标速度：u_t = x_1 - x_0
    · 训练：L = E_{t,x_0,x_1} [||v_θ(x_t, t) - (x_1 - x_0)||²]
  • 与扩散模型的关系：Flow Matching 可以看作一种更简洁的扩散模型，不需要噪声调度
  • 优势：训练更稳定，推理路径更直，采样步数更少

推荐资源：

  • 论文 "Flow Matching for Generative Modeling" (Lipman et al., ICLR 2023)
  • 论文 "Stochastic Interpolants" (Albergo & Vanden-Eijnden, 2023)

🎭 4.1 MDM: Motion Diffusion Model (ICLR 2023)

第一个将扩散模型成功应用于文本驱动运动生成的工作。这是你的入门必读论文。

核心架构：

  • 去噪网络：Transformer-based（不是 U-Net！），输入是运动序列 x_t ∈ R^{T×D}
    · T 是帧数，D 是每帧的运动维度
    · 时间步 t 通过 sinusoidal embedding 编码
    · 文本条件通过交叉注意力注入
  • 运动表示：使用 HumanML3D 的表示（关节位置 + 速度 + 脚接触标签）
  • 分类器引导：训练一个运动质量分类器来提升生成质量
  • 关键创新：证明了 Transformer 可以作为扩散模型的去噪网络处理序列运动数据

推荐资源：

  • 论文 "Human Motion Diffusion Model" (Tevet et al., ICLR 2023) — 必读
  • 代码 GitHub: GuyTevet/motion-diffusion-model — 官方实现，必读代码
  • 视频 YouTube 搜索 "MDM motion diffusion model ICLR 2023"

代码阅读指南：

  • 先看 model/diffusion.py — 扩散过程的核心实现
  • 再看 model/networks.py — Transformer 去噪网络
  • 然后看 data_loaders/humanml/ — 数据加载和表示
  • 最后看 train.py — 训练循环

🎨 4.2 MotionDiffuse (TPAMI 2024)

使用 U-Net 架构做运动扩散的代表工作，在某些指标上优于 MDM。

核心架构：

  • 去噪网络：1D U-Net（类似图像扩散但用 1D 卷积）
    · 时间步通过 FiLM (Feature-wise Linear Modulation) 注入
    · 文本通过交叉注意力注入
  • 多粒度文本嵌入：同时使用词级和句子级文本特征
  • 运动表示：直接用 SMPL 参数（轴角表示）

推荐资源：

  • 论文 "MotionDiffuse: Text-Driven Human Motion Generation with Diffusion Model" (Zhang et al., TPAMI 2024)
  • 代码 GitHub: mingyuan-zhang/MotionDiffuse

🗜️ 4.3 MLD: Motion Latent Diffusion

先将运动压缩到隐空间，再在隐空间做扩散 — 类似 Stable Diffusion 的思路。

核心架构：

  • VQ-VAE 编码器：将运动序列压缩到低维隐空间
    · 编码器：运动 → 隐向量 z
    · 解码器：隐向量 z → 运动
    · 向量量化 (VQ) 或连续隐空间
  • 隐空间扩散：在 z 空间做扩散，计算量大大减少
  • 优势：更快的训练和推理，更好的解耦

推荐资源：

  • 论文 "Human Motion Generation with Multimodal Latent Diffusion" (Chen et al., CVPR 2023)
  • 代码 GitHub: MotionLatentDiffusion

🦎 4.4 Kimodo 架构深度解析 (重点！)

NVIDIA 的 Kimodo 是你正在使用的核心模型。你需要从"会用"升级到"深入理解"。

核心架构组件：

  • 去噪器 (Denoiser)：
    · 基于 Transformer 的架构处理运动序列
    · 时间步编码：sinusoidal embedding + MLP
    · 位置编码处理序列中的帧位置
  • 文本编码器 (Text Encoder)：
    · 通常使用预训练的 CLIP 或 T5 模型
    · 文本特征通过交叉注意力与运动特征交互
    · CFG 需要同时处理有条件和无条件输入
  • 约束系统 (Constraints)：
    · 关节限位约束：确保生成的关节角度在物理可行范围内
    · 碰撞约束：避免身体部位穿透
    · 接触约束：脚部与地面的接触逻辑
    · 末端位置约束：指定手或脚的目标位置
  • 运动表示：
    · SOMA 骨架模型
    · 6D 旋转表示
    · 根节点归一化
  • 后处理流程：
    · 扩散生成 → 运动重定向 (Retargeting) → 跟踪控制 (Tracking)
    · 从人形运动到机器人可执行的运动

学习策略：

  1. 先完整阅读 Kimodo 的 Docker 镜像中的代码结构
  2. 找到模型定义文件，逐层理解网络结构
  3. 找到配置文件，理解每个超参数的含义
  4. 用调试模式跑一次推理，打印每一步的 tensor shape
  5. 修改 CFG 的 w 值，观察输出变化

⚡ 4.5 MotionLCM: 实时运动生成

基于一致性模型的实时运生成，采样步数只需 1-2 步。

核心概念：

  • 运动一致性模型：将运动扩散模型蒸馏为一致性模型
  • 单步/两步生成：从噪声直接映射到运动，延迟极低
  • 实时应用：可用于交互式运动生成、游戏、实时控制

推荐资源：

  • 论文 "MotionLCM: Real-time Controllable Motion Generation via Latent Consistency Model" (Dai et al., 2024)

🏗️ 5.1 MuJoCo 基础

MuJoCo 是机器人仿真的事实标准。你需要掌握建模、仿真和渲染。

核心概念：

  • MJCF 格式：MuJoCo 的原生 XML 格式，描述机器人模型
    · <worldbody>: 刚体层级结构
    · <joint>: 关节定义（hinge, slide, ball, free）
    · <actuator>: 执行器（电机、气缸）
    · <geom>: 几何形状（碰撞和可视）
    · <sensor>: 传感器（力、速度、加速度）
  • MuJoCo 物理引擎：
    · 接触动力学：软接触模型、摩擦锥
    · 约束求解器：PGS (Projected Gauss-Seidel)
    · 积分器：Euler, RK4, implicit
  • Python API：
    · mujoco.MjModel.from_xml_path() — 加载模型
    · mujoco.mj_step() — 仿真步进
    · mujoco.mj_forward() — 正运动学
    · mujoco.mj_inverse() — 逆运动学
  • 渲染：mujoco.Renderer — 可以渲染 RGB、深度图

推荐资源：

  • 文档 MuJoCo 官方文档 — 最权威的参考
  • 代码 DeepMind MuJoCo GitHub
  • 视频 YouTube 搜索 "MuJoCo tutorial python 2024"
  • 代码 dm_control — DeepMind 的 MuJoCo Python 封装

🏃 5.2 强化学习与运动控制

用 RL 训练人形机器人的行走策略，这是 sim-to-real 的基础。

核心概念：

  • PPO (Proximal Policy Optimization)：
    · 策略梯度方法，用 clipping 限制策略更新幅度
    · L^{CLIP} = E[min(r_t(θ)A_t, clip(r_t(θ), 1-ε, 1+ε)A_t)]
    · 人形运动控制的首选算法
  • SAC (Soft Actor-Critic)：
    · 最大熵 RL，鼓励探索
    · 连续动作空间的 off-policy 算法
    · 适合精细操作任务
  • 运动控制的 RL 设计：
    · 奖励函数设计：速度跟踪、能量效率、姿态稳定性
    · 观测空间：关节角度、角速度、IMU 数据、根节点高度
    · 动作空间：关节力矩或目标角度
    · Episode 设计：何时 reset、终止条件
  • 课程学习 (Curriculum Learning)：从简单任务逐步增加难度

推荐资源：

  • 论文 "Proximal Policy Optimization Algorithms" (Schulman et al., 2017)
  • 课程 OpenAI Spinning Up in Deep RL — 最好的 RL 入门资源
  • 代码 CleanRL — 单文件 RL 实现，含 PPO + MuJoCo
  • 代码 Stable Baselines3 — 生产级 RL 库
  • 视频 David Silver — UCL RL 课程 — 经典系列
  • 书籍 Reinforcement Learning: An Introduction (Sutton & Barto) — 免费在线

🌉 5.3 Sim-to-Real 迁移

在仿真中训练的策略如何部署到真实机器人上？这是最大的挑战之一。

核心概念：

  • Domain Randomization (域随机化)：
    · 随机化物理参数：质量、摩擦、阻尼
    · 随机化视觉：纹理、光照、相机参数
    · 随机化动力学：延迟、噪声
    · 核心思想：如果策略在足够多样的仿真环境中都能工作，它在真实环境中也能工作
  • System Identification (系统辨识)：
    · 从真实数据中估计仿真参数
    · 使仿真尽可能接近真实
  • Teacher-Student 范式：
    · Teacher：在仿真中用特权信息（完整状态）训练
    · Student：用 Teacher 的行为做监督，但只用可观测信息
    · Student 可以部署到真实机器人
  • NVIDIA Isaac Sim / Isaac Lab：
    · GPU 并行仿真：同时运行数千个环境
    · PhysX 5 物理引擎
    · 与 Kimodo pipeline 的集成

推荐资源：

  • 论文 "Domain Randomization for Transferring Deep Neural Networks from Simulation to the Real World" (Tobin et al., 2017)
  • 论文 "Learning Agile and Dynamic Motor Skills for Legged Robots" (Hwangbo et al., Science Robotics 2019) — Teacher-Student 的经典应用
  • 代码 NVIDIA Isaac Lab
  • 视频 YouTube 搜索 "NVIDIA Isaac Sim humanoid tutorial"

🤖 5.4 全身人形机器人控制

将运动扩散模型生成的运动转化为机器人可执行的控制信号。

核心概念：

  • 运动重定向 (Motion Retargeting)：
    · 人形运动 → 机器人运动：骨架差异、比例差异
    · 逆运动学求解：给定期望末端位置，求关节角度
    · 物理可行性检查：力矩限制、关节限位
  • 运动跟踪 (Motion Tracking)：
    · 用 RL 或 MPC 跟踪参考运动
    · PD 控制器：τ = K_p(q_ref - q) + K_d(q̇_ref - q̇)
    · 全身动力学：考虑接触力、平衡
  • MPC (Model Predictive Control)：
    · 在有限时域内优化控制序列
    · 适用于需要实时反应的场景
  • Kimodo Pipeline：
    · 文本 → 运动扩散 → 运动重定向 → 运动跟踪 → 机器人执行
    · 每一步都有物理约束和可行性检查

推荐资源：

  • 论文 "Learning Physically Simulated Humanoid Skills from Motion Capture Data" (Luo et al., 2023)
  • 论文 "Expressive Whole-Body Control for Humanoid Robots" (Luo et al., 2024)

🌐 6.1 VLA 模型：从 RT-2 到 pi0

Vision-Language-Action 模型是机器人基础模型的最新范式。

核心模型：

  • RT-2 (Robotics Transformer 2)：
    · Google DeepMind, 2023
    · 将大型 VLM 微调为动作输出模型
    · 动作被 token 化为整数（如 "1 128 91 241 5 101"）
    · 利用网络知识进行机器人控制
    · 论文：arxiv 2307.15818
  • Octo：
    · 开源通用机器人策略，2024
    · 在 Open X-Embodiment 数据集上训练（800k+ 轨迹）
    · 模块化架构：可适配不同机器人和任务
    · 论文：arxiv 2405.12213
  • OpenVLA：
    · 开源 VLA，基于 Prismatic VLM（7B 参数）
    · 可微调到特定机器人和任务
    · 论文：arxiv 2406.09246
  • pi0 (Physical Intelligence)：
    · 使用 Flow Matching 生成连续动作
    · 跨多种机器人 embodiment 训练
    · 代表了 VLA + Flow Matching 的最新方向
    · 论文：arxiv 2410.24164

关键趋势：

  • 从离散动作 token（RT-2）到连续动作生成（pi0）的演进
  • 从单一机器人到多 embodiment 的泛化
  • 扩散/Flow 模型在动作生成中的核心地位
  • 预训练 → 微调的范式从 NLP 迁移到机器人学

🎮 6.2 Diffusion Policy

将扩散模型直接用于机器人控制策略学习，是 VLA 的重要分支。

核心概念：

  • 核心思想：将策略 π(a|s) 建模为条件扩散模型
    · 输入：视觉观测 + 机器人状态
    · 输出：未来 K 步的动作序列
    · 用扩散过程处理多模态动作分布
  • 为什么用扩散：
    · 传统方法（如 BC）难以处理多模态分布
    · 扩散模型天然适合建模多模态分布
    · 训练稳定，不需要对抗训练
  • 架构选择：
    · U-Net backbone：处理视觉输入
    · 时间步编码：与 DDPM 相同
    · 观测条件：通过 FiLM 或交叉注意力
  • 关键结果：在 Push-T、RoboMimic 等基准上达到 SOTA

推荐资源：

  • 论文 "Diffusion Policy: Visuomotor Policy Learning via Action Diffusion" (Chi et al., RSS 2023) — 必读
  • 代码 GitHub: real-stanford/diffusion_policy
  • 视频 YouTube 搜索 "Diffusion Policy robot manipulation"

🔗 6.3 Kimodo 下游 Pipeline

理解 Kimodo 的运动输出如何转化为真实机器人的行为。

Pipeline 流程：

  1. 文本输入：自然语言描述期望的运动（如"向前走三步然后转身"）
  2. 运动扩散生成：Kimodo 生成符合描述的人形运动序列
  3. 运动重定向 (Retargeting)：
    · 从 SOMA 人形骨架 → 目标机器人骨架
    · 处理骨架差异（关节数量、比例、自由度）
    · 保持运动的物理合理性
  4. 运动跟踪控制 (Tracking)：
    · 用 RL 策略跟踪重定向后的参考运动
    · 处理物理仿真中的偏差
    · 实时调整以保持平衡
  5. Sim-to-Real 部署：
    · 域随机化确保仿真策略迁移到真实机器人
    · 状态估计和传感器融合
    · 安全约束和急停机制

核心公式速查

高斯扩散 (DDPM)

前向加噪
q(x_t | x_0) = N(x_t; √ᾱ_t · x_0, (1 - ᾱ_t) · I)
重参数化
x_t = √ᾱ_t · x_0 + √(1 - ᾱ_t) · ε, ε ~ N(0, I)
训练目标
L = E_{t, x_0, ε} [ ||ε - ε_θ(x_t, t)||² ]
DDPM 采样
x_{t-1} = (1/√α_t)(x_t - β_t/√(1-ᾱ_t) · ε_θ(x_t,t)) + σ_t · z

Classifier-Free Guidance

CFG 公式
ε̃ = ε_θ(x_t, t, ∅) + w · (ε_θ(x_t, t, c) - ε_θ(x_t, t, ∅))
其中
w = 引导强度 (通常 2.5-7.5) c = 有条件输入 (如文本嵌入) ∅ = 无条件输入 (如空字符串)

Flow Matching

插值路径
x_t = (1 - t) · x_0 + t · x_1 其中 x_0 ~ N(0,I), x_1 ~ p_data
训练目标
L = E_{t, x_0, x_1} [ ||v_θ(x_t, t) - (x_1 - x_0)||² ]

旋转表示

Rodrigues 公式 (轴角 → 旋转矩阵)
R = I + sin(θ)·[ω]_× + (1-cos(θ))·[ω]_×² 其中 [ω]_× 是反对称矩阵
6D → 旋转矩阵 (Zhou et al.)
输入: a₁, a₂ ∈ R³ (旋转矩阵前两列) b₁ = normalize(a₁) b₂ = normalize(a₂ - (a₂·b₁)b₁) b₃ = b₁ × b₂ R = [b₁ | b₂ | b₃]

齐次变换

SE(3) 变换矩阵
T = [ R t ] R ∈ SO(3), t ∈ R³ [ 0 1 ] T₁ · T₂ = [R₁R₂ R₁t₂+t₁] [ 0 1 ]
正运动学
T_0n = T_01 · T_12 · ... · T_(n-1)n 末端位置 = T_0n · [0,0,0,1]ᵀ

PPO

PPO-Clip 目标
L^{CLIP} = E[min(r_t(θ)A_t, clip(r_t(θ), 1-ε, 1+ε)A_t)] r_t(θ) = π_θ(a|s) / π_{θ_old}(a|s)

卡住时怎么办

数学看不懂？

  • 先看直觉，再看公式：先看 3Blue1Brown 的视频建立直觉，再回到论文公式
  • 手推一遍：拿纸笔把关键推导手写一遍，不要只用眼睛看
  • 简化到 2D：先在 2D 空间理解概念（如 2D 高斯的扩散），再推广到高维
  • ChatGPT/Claude：把公式贴给 AI，让它用通俗语言解释

代码跑不通？

  • Docker 环境：确保 Docker 容器内的 CUDA、PyTorch 版本匹配
  • Shape 调试：在关键位置插入 print(x.shape)，确认 tensor 维度正确
  • 小数据集测试：先在 10-100 个样本上过拟合，确认代码逻辑正确
  • RTX 5090 注意：确认 PyTorch 版本支持你的 GPU 架构，可能需要 nightly 版本
  • 内存问题：用 nvidia-smi 监控显存，考虑 gradient accumulation

概念混淆？

  • 画图：用纸笔或 draw.io 画出模型架构、数据流、损失函数的关系
  • 对比表格：列出不同方法的异同（如 DDPM vs DDIM vs Flow Matching）
  • 写博客：尝试用自己的话写一篇解释，教是最好的学
  • GitHub Issues：在相关仓库的 Issues 中搜索，往往有人问过类似问题

训练不收敛？

  • 学习率：从 1e-4 开始，太大 loss 会震荡，太小收敛慢
  • 数据检查：可视化几个 batch 的数据，确认没有异常值
  • Loss 曲线：用 TensorBoard/WandB 监控 loss，观察是否在下降
  • 梯度检查：监控梯度范数，确认没有梯度爆炸或消失
  • 过拟合测试：先在小数据集上确认能过拟合，再扩大数据量

论文读不懂？

  • 先读代码：有时候代码比论文更清晰，先跑通代码再回头读论文
  • 找讲解视频：YouTube 上搜 "paper_name explained" 或 "paper_name walkthrough"
  • 读引用论文：如果某篇论文的基础概念不懂，先去读它引用的基础论文
  • Reddit / Twitter：r/MachineLearning 和 ML Twitter 上经常有论文讨论

GPU 资源管理（RTX 5090 x2-3）

  • 并行训练：用 DistributedDataParallel 在多卡上训练
  • 混合精度：用 torch.cuda.amp 节省约 40% 显存
  • Gradient Checkpointing：用时间换空间，减少显存占用
  • Batch Size：RTX 5090 有 32GB 显存，可以尝试较大 batch size
  • 服务器任务管理：用 tmux 管理长时间训练任务，避免 SSH 断开导致训练中断
  • WandB：用 WandB 监控远程训练，避免频繁 SSH
