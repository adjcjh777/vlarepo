一、研究方向概述

1.1 核心问题

人形机器人运动控制领域面临一个根本性挑战：如何将文本描述的高层运动意图转化为物理可行、可部署的全身运动策略。尽管近年来扩散模型（如 Kimodo）在运动生成方面取得了突破性进展，能够从文本生成高质量的人体运动轨迹，但这些生成的运动本质上是运动学层面的——它们不考虑物理约束、动力学可行性以及机器人本体的具体限制。

Sim-to-Real RL Tracking 方向旨在弥合这一鸿沟：将 Kimodo 生成的运动轨迹作为参考信号，在物理仿真环境（MuJoCo/Isaac Sim）中训练强化学习策略，使策略学会在物理约束下跟踪这些参考运动，最终实现零样本（zero-shot）迁移到真实机器人硬件。

1.2 为什么这个方向有前景

三大驱动力：
  • 高质量运动生成器已就绪：Kimodo 在 700 小时光学动捕数据上训练，支持文本、关键帧、关节位置/旋转、2D 路径等多种控制信号，为 RL 训练提供了丰富的参考运动源。
  • RL 训练效率大幅提升：最新研究表明（如 FastSAC/FastTD3），在单张 RTX 4090 上仅需 15 分钟即可训练出可部署的人形运动策略，使得快速迭代实验成为可能。
  • Sim-to-Real 迁移技术成熟：域随机化、教师-学生蒸馏、可微仿真系统辨识等技术已形成成熟的工程方法论，多项工作在 Unitree G1 上实现了零样本迁移。

1.3 研究定位

本研究的核心创新点在于：利用 Kimodo 作为运动学参考生成器，结合最新的人形机器人 RL 跟踪技术，构建一个从文本描述到物理可行运动的完整管线。具体而言：

1.4 计算资源评估

用户拥有 2-3 块 RTX 5090 GPU。根据最新研究，单块消费级 GPU 即可训练人形运动策略。RTX 5090 的 32GB 显存和高算力使得大规模并行仿真训练完全可行，预计单个策略训练可在 10-30 分钟内完成，非常适合快速迭代实验。

二、文献综述

2.1 核心参考：Kimodo 运动扩散模型

Kimodo: Scaling Controllable Human Motion Generation
Davis Rempe, Mathis Petrovich, Ye Yuan, Haotian Zhang, Xue Bin Peng, et al.
arXiv 2026.03
arXiv:2603.15546
Kimodo 是 NVIDIA 推出的运动学运扩散模型，在 700 小时光学动捕数据上训练。它使用精心设计的运动表示和两阶段去噪架构（分离根节点和身体预测），支持文本和多种运动学约束（全身关键帧、稀疏关节位置/旋转、2D 路径点、稠密 2D 路径）控制。论文研究了数据集和模型规模的扩展效应。
与本研究的关系: 作为运动学参考轨迹的生成器，是整个管线的起点。Kimodo 生成的运动将作为 RL 跟踪策略的参考信号。

2.2 运动跟踪与模仿学习

Learning Whole-Body Humanoid Locomotion via Motion Generation and Motion Tracking
Zewei Zhang, Kehan Wen, Michael Xu, Junzhe He, Chenhao Li, Takahiro Miki, Clemens Schwarke, Chong Zhang, Xue Bin Peng, Marco Hutter
arXiv 2026.04
arXiv:2604.17335
与本研究方向最直接相关的工作。该框架结合了两个核心组件：(1) 地形感知运动生成——使用扩散模型预测地形感知的参考运动；(2) 全身运动跟踪——使用 RL 训练全身参考跟踪器。为处理不完美的生成参考，跟踪器在闭环设置中进一步微调。系统在 Unitree G1 上部署，成功跨越箱子、栏杆、楼梯和混合地形。
直接对标本研究的管线设计。其"运动生成 + RL 跟踪 + 闭环微调"的三阶段框架是本研究的核心参考。
RobotDancing: Residual-Action Reinforcement Learning Enables Robust Long-Horizon Humanoid Motion Tracking
Zhenguo Sun, Yibo Peng, Yuan Meng, Xukun Li, Bo-Sheng Huang, Zhenshan Bing, Xinlong Wang, Alois Knoll
arXiv 2025.09
arXiv:2509.20717
提出残差动作 RL 框架，预测残差关节目标来显式修正动力学差异，而非发送绝对关节命令。使用统一的观测、奖励和超参数配置的单阶段 RL 设置。在 Unitree G1 上评估，可跟踪多分钟的高动态行为（跳跃、旋转、侧翻），零样本迁移到硬件。
残差动作空间设计对本研究极具参考价值。相比直接输出关节角度，残差方式能更好地处理模型-实际不匹配。
Constrained Whole-Body Tracking for Humanoid Robots (ConstrainedMimic)
Daniel Morton, Pranit Mohnot, Marco Pavone
arXiv 2026.06
arXiv:2606.00374
将操作空间控制和控制屏障函数（CBF）集成到 RL 跟踪策略中，在运行时强制执行安全约束（碰撞避免、关节限位、质心稳定性）。约束在运行时指定而非烘焙到训练中。在 CPU/GPU/TPU 上以 300-500 Hz 运行。
为本研究提供了安全约束保障的思路，确保 RL 策略在跟踪 Kimodo 运动时满足物理安全约束。
TWIST: Teleoperated Whole-Body Imitation System
Yanjie Ze, Zixuan Chen, João Pedro Araújo, Zi-ang Cao, Xue Bin Peng, Jiajun Wu, C. Karen Liu
arXiv 2025.05
arXiv:2505.02833
通过运动重定向将人类动捕数据转化为机器人参考运动，然后使用 RL+BC（强化学习 + 行为克隆）训练全身控制器。证明了特权未来运动帧和真实世界动捕数据可提高跟踪精度。单一神经网络控制器即可实现全身操纵、足式操纵、运动和表达性动作。
RL+BC 混合训练方法和未来帧信息的使用对本研究有重要参考价值。
Retargeting Matters: General Motion Retargeting for Humanoid Motion Tracking
Joao Pedro Araujo, Yanjie Ze, Pei Xu, Jiajun Wu, C. Karen Liu
arXiv 2025.10
arXiv:2510.02252
系统性评估重定向质量如何影响策略性能。提出 GMR（General Motion Retargeting）方法，在 LAFAN1 数据集上证明重定向引入的伪影（脚滑、自穿插）会显著降低策略鲁棒性，尤其是对动态或长序列。GMR 一致优于现有开源方法。
关键洞察：重定向质量直接决定 RL 策略的性能上限。对本研究中 G1→ELF3 的重定向环节有重要指导意义。
SoftMimic: Learning Compliant Whole-body Control from Examples
Gabriel B. Margolis, Michelle Wang, Nolan Fey, Pulkit Agrawal
arXiv 2025.10
arXiv:2510.17792
指出 RL 模仿方法倾向于激励刚性控制，导致不安全行为。使用逆运动学构建可行柔顺运动的增强数据集，训练策略匹配柔顺响应而非刚性跟踪参考。在真实世界中实现了安全有效的环境交互。
柔顺控制思想对 ELF3 机器人的真实部署尤为重要，可避免刚性跟踪导致的硬件损伤。

2.3 对抗运动先验与奖励设计

AMP: Adversarial Motion Priors for Stylized Physics-Based Character Control
Xue Bin Peng, Ze Ma, Pieter Abbeel, Sergey Levine, Angjoo Kanazawa
ACM SIGGRAPH 2021
arXiv:2104.02180
开创性地提出对抗运动先验方法。使用风格判别器区分"自然"和"不自然"运动，将判别器输出作为 RL 奖励信号。无需配对的状态-动作动捕数据，仅需无结构的运动片段即可训练。不同技能的组合从运动先验中自动涌现。
AMP 是运动跟踪 RL 的基础方法论。其对抗式奖励设计避免了手工设计模仿目标的繁琐，对本研究的奖励函数设计有奠基性影响。
SMP: Reusable Score-Matching Motion Priors for Physics-Based Character Control
Yuxuan Mu, Ziyu Zhang, Yi Shi, Dun Yang, Minami Matsumoto, et al.
ACM Transactions on Graphics (SIGGRAPH 2026)
arXiv:2512.03028
使用预训练的运动扩散模型结合分数蒸馏采样（SDS）构建可复用、任务无关的运动先验。与 AMP 不同，SMP 先验可在运动数据集上预训练，独立于任何控制策略或任务，然后冻结作为通用奖励函数训练新策略。支持风格组合和迁移。
与 Kimodo 的结合潜力巨大。可将 Kimodo 作为预训练的运动扩散模型，通过 SDS 构建可复用的运动先验，避免为每个新任务重新训练对抗判别器。
RL from Physical Feedback: Aligning Large Motion Models with Humanoid Control
Junpeng Yue, Zepeng Wang, Yuxuan Wang, et al.
arXiv 2025.06
arXiv:2506.12769
提出 RLPF 框架，使用运动跟踪策略在物理仿真器中评估运动生成器输出的物理可行性，产生奖励信号来微调运动生成器。包含对齐验证模块确保生成运动保持文本语义一致性。在真实人形机器人上成功部署。
提供了将物理反馈注入运动生成器的闭环框架，可用于改进 Kimodo 的输出使其更加物理可行。
Advanced Skills through Multiple Adversarial Motion Priors in Reinforcement Learning
Eric Vollenweider, Marko Bjelonic, Victor Klemm, Nikita Rudin, Joonho Lee, Marco Hutter
arXiv 2022.03
arXiv:2203.14912
扩展 AMP 到多个对抗运动先验的组合，实现更复杂技能的学习。使用多个判别器分别处理不同运动模式，支持更丰富运动技能的涌现。
多判别器架构可处理 Kimodo 生成的多样化运动模式（行走、跑步、转身等）。

2.4 Sim-to-Real 迁移

Learning Sim-to-Real Humanoid Locomotion in 15 Minutes
Younggyo Seo, Carmelo Sferrazza, Juyue Chen, Guanya Shi, Rocky Duan, Pieter Abbeel
arXiv 2025.12
arXiv:2512.01996
训练效率的里程碑。提出基于 off-policy RL（FastSAC 和 FastTD3）的简洁实用方案，在单张 RTX 4090 上 15 分钟内训练出人形运动策略。通过精心调优的设计选择和极简奖励函数稳定大规模并行环境下的 off-policy RL。在 Unitree G1 和 Booster T1 上验证，包含强域随机化。
直接影响本研究的实验效率。15 分钟的训练时间意味着可以在 2-3 块 RTX 5090 上进行大量消融实验。
HALO: Closing Sim-to-Real Gap for Heavy-loaded Humanoid Agile Motion Skills via Differentiable Simulation
Xingyi Wang, Chenyun Zhang, Weiji Xie, Chao Yu, Wei Song, Chenjia Bai, Shiqiang Zhu
arXiv 2026.03
arXiv:2603.15084
使用可微仿真器 MuJoCo XLA 进行两阶段梯度系统辨识。第一阶段从真实数据校准标称机器人模型，第二阶段识别未知载荷的质量分布。实现了重载条件下 RL 策略的零样本迁移。
可微仿真系统辨识方法可用于精确校准 ELF3 的 MuJoCo 模型参数，缩小 sim-to-real gap。
HuB: Learning Extreme Humanoid Balance
Tong Zhang, Boyuan Zheng, Ruiqian Nai, Yingdong Hu, Yen-Jen Wang, et al.
CoRL 2025 (Oral)
arXiv:2505.07294
结合参考运动精炼、平衡感知策略学习和 sim-to-real 鲁棒性训练三个组件。在 Unitree G1 上实现极端准静态平衡任务（如高踢腿 1.5 米以上），在强力足球击打等强扰动下保持稳定。
三组件框架（运动精炼 + 平衡学习 + sim-to-real 鲁棒性）与本研究的管线高度互补。
BFM-Zero: A Promptable Behavioral Foundation Model for Humanoid Control Using Unsupervised Reinforcement Learning
Yitang Li, Zhengyi Luo, Tonghe Zhang, et al.
arXiv 2025.11
arXiv:2511.04131
构建共享潜在表示将运动、目标和奖励嵌入到公共空间，使单一策略处理多个下游任务而无需重新训练。基于无监督 RL 和 Forward-Backward 模型。在 Unitree G1 上实现零样本运动跟踪、目标到达和少样本适应。
基础模型思路代表了人形控制的长期方向，可作为本研究管线的未来扩展。

2.5 扩散策略与生成式 RL

Diffusion Policy: Visuomotor Policy Learning via Action Diffusion
Cheng Chi, Zhenjia Xu, Siyuan Feng, et al.
RSS 2023 / IJRR 2024
arXiv:2303.04137
将机器人的视觉运动策略表示为条件去噪扩散过程。在 12 个任务上平均提升 46.9%。核心优势：处理多模态动作分布、适合高维动作空间、训练稳定性好。
扩散策略的表示能力可作为 RL 策略的替代方案，尤其适合处理人形机器人控制中的多模态性。
GenPO: Generative Diffusion Models Meet On-Policy Reinforcement Learning
Shutong Ding, Ke Hu, Shan Zhong, et al.
NeurIPS 2025
arXiv:2505.18763
首次成功将扩散策略整合到 on-policy RL（PPO）中。使用精确扩散反转构建可逆动作映射，通过双虚拟动作机制实现可逆性。在 IsaacLab 的 8 个基准上评估，包括 Unitree H1 人形和四足机器人。
解决了扩散策略与 PPO 结合的技术难题，为使用扩散策略作为人形控制策略提供了理论和实践基础。
DreamPolicy: A Unified World-model Policy for Scalable Humanoid Locomotion
Yahao Fan, Tianxiang Gui, Kaiyang Ji, et al.
arXiv 2025.05
arXiv:2505.18780
结合离线数据和基于扩散的世界模型，单一策略可处理已知和未知地形。地形感知世界模型生成物理合理的未来轨迹作为策略的动态目标。在未见地形上超越最强基线 27%，组合地形上超越 38%。
世界模型方法可增强策略对未见运动模式的泛化能力。

3.2 阶段一：运动参考数据准备

3.2.1 Kimodo 运动生成

  • 使用 Kimodo 的文本到运动生成能力，生成多样化的参考运动轨迹
  • 利用 Kimodo 的约束控制能力（关键帧、路径点）精细控制运动
  • 生成的运动为 SMPL 格式，包含关节位置和旋转
  • 批量生成覆盖不同运动模式（行走、跑步、转向、蹲起等）的运动库

3.2.2 运动重定向 (G1 → ELF3)

  • 关键挑战：Kimodo 默认生成 SMPL 人体运动，需先重定向到 Unitree G1，再从 G1 重定向到 ELF3
  • 参考 GMR (General Motion Retargeting) 方法，减少重定向伪影
  • 特别注意脚部接触约束——避免脚滑和穿插
  • 验证重定向后运动的物理合理性

3.3 阶段二：RL 策略训练

3.3.1 动作空间设计

推荐：残差动作空间 (Residual Action Space)

参考 RobotDancing 和 HDMI 的设计，RL 策略输出残差关节目标而非绝对关节角度：

a_t = a_kinematic + delta_a_rl
# a_kinematic: 来自 Kimodo 运动的运动学目标
# delta_a_rl: RL 策略学习的残差修正

这种设计的优势：(1) 运动学目标提供了良好的初始化；(2) RL 只需学习修正动力学差异；(3) 更容易收敛且更鲁棒。

3.3.2 观测空间设计

参考 ConstrainedMimic 和 TWIST 的设计，观测应包含：

  • 本体感知：关节角度、关节角速度、IMU（躯干方向和角速度）、足底力传感器
  • 参考运动：当前帧和未来 N 帧的参考关节目标（未来帧信息显著提升跟踪精度）
  • 命令信号：目标速度、转向角等高层命令
  • 历史信息：过去 K 帧的观测历史（提升鲁棒性）

3.3.3 奖励函数设计

采用多目标分层奖励，参考 HuB 和 TWIST 的设计：

奖励项 权重范围 说明
关节位置跟踪 1.0 - 2.0 参考运动关节角度的 L2 距离
关节速度跟踪 0.1 - 0.5 参考运动关节角速度匹配
根节点位置跟踪 1.0 - 2.0 根节点高度和水平位置
根节点方向跟踪 0.5 - 1.0 躯干朝向四元数匹配
脚部接触奖励 0.5 - 1.5 摆动/支撑相的脚部接触状态
生存奖励 1.0 每步存活的基础奖励
动作平滑性 -0.01 ~ -0.1 惩罚关节抖动和不连续
能量消耗 -0.001 ~ -0.01 惩罚过大关节力矩
姿态正则化 -0.1 ~ -0.5 惩罚不自然的关节配置

3.3.4 RL 算法选择

推荐方案（按优先级）：
  1. PPO (Proximal Policy Optimization)：最成熟稳定的 on-policy 算法，与 Isaac Sim/Gym 的大规模并行环境配合良好。GenPO 证明了扩散策略可与 PPO 结合。
  2. FastSAC / FastTD3：如果训练效率是瓶颈，参考"15分钟训练"方案使用 off-policy 方法，可在消费级 GPU 上极速训练。
  3. AMP + PPO：如果需要更自然的运动风格，可引入对抗运动先验作为额外奖励信号。

3.4 阶段三：Sim-to-Real 迁移

3.4.1 域随机化

参考 FastSAC 和 HALO 的域随机化策略：

随机化类别 参数范围 目的
物理参数 摩擦系数 ±30%、质量 ±20%、阻尼 ±30% 补偿建模误差
关节参数 关节偏移 ±5°、力矩限制 ±10% 补偿装配误差
传感器噪声 IMU 高斯噪声、关节编码器噪声 模拟真实传感器
外部扰动 随机推力 10-50N、地形坡度 ±5° 提升鲁棒性
延迟 控制延迟 10-40ms 模拟通信延迟

3.4.2 系统辨识

参考 HALO 的可微仿真系统辨识方法：

  • 使用 MuJoCo XLA 的可微仿真能力，通过梯度优化校准 ELF3 模型参数
  • 两阶段方法：先校准标称模型，再识别载荷变化
  • 重点关注关节摩擦、阻尼、电机响应特性

3.4.3 Teacher-Student 蒸馏

  • Teacher 策略在仿真中使用特权信息（完整状态、地形信息等）训练
  • Student 策略仅使用可部署的观测（本体感知 + 参考运动）进行蒸馏
  • 使用 DAgger 或在线蒸馏方法

3.5 阶段四：ELF3 部署

  • 在 MuJoCo 中验证策略后，进行 sim-to-sim 迁移测试（MuJoCo → 其他仿真器验证鲁棒性）
  • 在 ELF3 真实硬件上进行低速安全测试
  • 逐步增加运动复杂度和速度
  • 部署时使用柔顺控制模式（参考 SoftMimic）保护硬件

5.2 最小可行实验

以下是一个最小的运动跟踪 RL 训练框架伪代码：

import torch
import numpy as np

class MotionTrackingEnv:
    """基于 MuJoCo 的运动跟踪环境"""
    def __init__(self, model_path, reference_motion, sim_dt=0.002, control_dt=0.02):
        self.model = mujoco.MjModel.from_xml_path(model_path)
        self.data = mujoco.MjData(self.model)
        self.reference = reference_motion  # Kimodo 生成的运动
        self.sim_dt = sim_dt
        self.control_dt = control_dt
        self.frame_skip = int(control_dt / sim_dt)

    def get_obs(self):
        """构建观测向量"""
        # 本体感知
        joint_pos = self.data.qpos[7:]  # 去掉根节点 7 自由度
        joint_vel = self.data.qvel[6:]
        torso_quat = self.data.qpos[3:7]
        imu_gyro = self.data.sensor('gyro').data

        # 参考运动 (当前帧 + 未来 N 帧)
        ref_current = self.reference[self.current_frame]
        ref_future = self.reference[self.current_frame:self.current_frame+5]

        return np.concatenate([
            joint_pos, joint_vel, torso_quat, imu_gyro,
            ref_current.flatten(), ref_future.flatten()
        ])

    def compute_reward(self):
        """计算多目标奖励"""
        # 关节位置跟踪
        pos_error = np.sum((self.data.qpos[7:] - self.reference[self.current_frame]) ** 2)
        r_tracking = np.exp(-5.0 * pos_error)

        # 存活奖励
        r_alive = 1.0

        # 摔倒惩罚
        torso_height = self.data.qpos[2]
        r_fall = -100.0 if torso_height < 0.5 else 0.0

        return r_tracking + r_alive + r_fall

    def step(self, action):
        """执行一步"""
        # 残差动作: 运动学目标 + RL 残差
        ref_target = self.reference[self.current_frame]
        target = ref_target + action  # 残差

        # 设置关节目标 (位置控制)
        self.data.ctrl[:] = target

        # 仿真步进
        for _ in range(self.frame_skip):
            mujoco.mj_step(self.model, self.data)

        self.current_frame += 1
        obs = self.get_obs()
        reward = self.compute_reward()
        done = self.current_frame >= len(self.reference) - 1
        return obs, reward, done, {}

# PPO 训练 (使用 rsl-rl 或 stable-baselines3)

7.2 定性评估标准

  • 运动自然度：通过视频回放人工评估，运动应看起来自然流畅，无明显抖动或不自然姿态
  • 跟踪保真度：策略执行的运动应与 Kimodo 参考运动在视觉上高度一致
  • 鲁棒性：策略应对轻微推扰和地面变化具有恢复能力
  • 安全性：关节力矩应在安全范围内，无突然的大力矩冲击

7.3 与现有工作的对比

对比基线选择：
  • 运动学回放：直接执行 Kimodo 重定向后的运动学目标（不使用 RL），预期在 MuJoCo 中因动力学不可行而失败
  • AMP-only：使用 AMP 对抗先验但不使用 Kimodo 参考运动，预期运动自然但跟踪精度低
  • 纯跟踪 RL：使用简单 L2 跟踪奖励但不使用残差动作空间，预期收敛慢且抖动大
  • Oracle：使用仿真中的完美状态信息，作为性能上界参考

8.1 里程碑与回退计划

关键决策点：
  • 里程碑 1（第 2 周）：如果 ELF3 MuJoCo 环境中行走跟踪误差 > 25°，需要重新审查重定向质量和奖励函数设计。
  • 里程碑 2（第 4 周）：如果 sim-to-sim 迁移成功率 < 50%，需要加强域随机化或改进系统辨识。
  • 里程碑 3（第 6 周）：如果端到端管线命令执行率 < 50%，考虑简化目标——先聚焦单个运动模式的高质量跟踪。
  • 回退选项：如果 ELF3 真实部署风险过高，可先在 Unitree G1 上验证管线，再迁移到 ELF3。
